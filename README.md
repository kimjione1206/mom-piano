# 엄마 피아노 🎹

위에서 내려오는 음표가 선에 닿으면 같은 색 건반을 누르는 안드로이드 피아노 게임.
음표는 건반을 누를 때까지 기다려 주기 때문에 틀려도 노래가 끝까지 이어진다.

노래 6곡(저작권이 끝난 옛 노래): 나비야 · 반짝반짝 작은별 · 떴다 떴다 비행기 · 생일 축하합니다 · 환희의 송가 · 징글벨

## 설치 (안드로이드 휴대폰)

1. 휴대폰에서 이 링크를 누른다: **https://github.com/kimjione1206/mom-piano/releases/latest/download/mom-piano.apk**
2. "파일이 유해할 수 있습니다" → **다운로드**
3. 받은 파일을 누름 → "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용** 켜고 뒤로
4. **설치** (Play 프로텍트가 "알 수 없는 앱"이라고 하면 **세부정보 → 무시하고 설치**)

## 만들기 (맥)

```bash
./build.sh
```

- `www/index.html` — 게임 전체 (노래 악보는 파일 위쪽 `SONGS`)
- `android/` — 게임 화면을 전체 화면으로 띄우는 앱 껍데기
- 서명 열쇠는 `~/.config/mom-piano/keystore.jks` (잃어버리면 새 버전을 덮어 설치할 수 없음)
